# Oráculo

![Oráculo theme preview](preview.png)

A dark Omarchy theme with blue-black surfaces, cool text and a steel-blue accent. The preview is original neo-expressionist artwork inspired by Jean-Michel Basquiat's visual language; it is not a desktop screenshot or a reproduction of a specific artwork.

[**Oráculo Light**](https://github.com/PedroAugustoOK/omarchy-oraculo-light-theme) is the cool-paper variant.

## Install

```bash
omarchy theme install https://github.com/PedroAugustoOK/omarchy-oraculo-theme
omarchy theme bg next
```

Installation applies the theme. The second command cycles its three static backgrounds.

`colors.toml` is the palette source; Omarchy generates application configurations from its templates. The repository does not ship Lua, terminal configuration files or `vscode.json`.

Reapply, update, refresh after an Omarchy upgrade, or remove the theme with `omarchy theme set oraculo`, `omarchy theme update`, `omarchy theme refresh` and `omarchy theme remove oraculo`.
